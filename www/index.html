Cabem no slot + centralizar: escala (nearest) para caber inteira no slot e centraliza em pixels inteiros — evita linha preta por desalinhamento.
Esticar: força exatamente o tamanho do slot (pode distorcer).

Não redimensionar: tamanho original, só centraliza (corta se for maior).

Limpar franja: remove pixels com alpha baixo, descontamina RGB da borda e zera RGB em alpha 0 — elimina a linha preta no jogo.
Alpha duro: tudo ≥ limiar vira 255; abaixo vira 0 (borda seca, pixel art).
Margem Balatro 1px: força 1 px transparente em volta (71×95 / 142×190).
IA: modelo de segmentação (1ª vez precisa internet para baixar o motor; depois pode usar cache).
Magic / Simple: 100% offline. Se a IA falhar, o app usa Magic automaticamente.
Use Limpar franja depois de remover o fundo (Balatro).
